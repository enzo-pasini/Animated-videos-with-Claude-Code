# Claude-Animation — project rules

- **Project map:** `docs/PROJECT_MAP.md` says what every folder and important file is and the current phase. Read it first when you need to find something.
- **Keep the map up to date:** whenever the structure changes (a folder or important file is added, moved, renamed or removed, a new tool, skill or command, or the phase changes), update `docs/PROJECT_MAP.md` in the same change.
- **Feedback:** `videos/<slug>/feedback.md` is written by the `explain-find-feedback` skill and applied **only** when the user runs `/feedback`.
